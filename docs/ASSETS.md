# 素材说明

## 封面和配图

使用内置 imagegen 工具生成手绘风格插画。共同提示词方向：暖色纸张、水彩与彩铅、深蓝中文手写标题、蓝色水滴、灰色阻塞格子、金色连接。

- cover.png：临界点／一滴水的通关之旅；金色通路连续连接岩石两端。
- 01-four-neighbors.png：3×3十字邻接与对角接触的反例。
- 02-cluster-bridge.png：5×5示意格子中，一个新增开放格子连接两个原本分离的小簇。
- 03-spanning-path.png：5×5示意网格中的左到右四邻接贯穿路径。

插画经过文字与邻接关系检查，均为概念示意。

## 视频与真实数据图

视频来自本项目的确定性教学动画。assets/frames中的八张PNG直接从完整MP4提取，统计图与simulation.json一致。视频中文旁白由MiniMax官方speech-2.8-hd、系统音色Chinese (Mandarin)_Gentleman合成。背景为本地生成的低音量音调与提示音。

不含API密钥、语音请求元数据、个人配置或系统字体文件。
